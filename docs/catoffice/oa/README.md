## 一页定位

给已经上了钉钉 / 企微 / 泛微（或什么都没上）的组织：**审批、客户、任务
留在你们的系统里，文档环节交给办公猫**。

- OA 是组织内网里**文档能力最强的一环**：服务端直接复用 `docx-engine`
  做模板套版与签发留痕（纯 TS 引擎包，服务端独立运行），桌面端经文档桥
  用真编辑器打开保存。
- **模块可拆可合**：从「单 Docker 的身份 + 审批 + 套版」到全家桶，按模块
  售卖；只装底座 + 单模块必须能跑（验收项）。
- **钉钉 / 企微是通道，不是对手**：通讯录同步、审批事件、消息通知走它们，
  我们补它们的文档短板。

明确不做：IM、日历、邮件、HR 业务（薪资 / 考勤 / 绩效）、工单系统本体、BI。
防膨胀条款见 [product-plan.md](product-plan.md) 第八节。
