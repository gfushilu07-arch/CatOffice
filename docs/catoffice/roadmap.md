## 二、节奏约定

- 每个工作项按既有节奏切刀：探底 → 实现 → 测试 → 提交 → 本表与专项文档
  双向回填。
- 大项（C1/C2/SA1）之间穿插小项（P1 扩充/C3）保持交付节奏。
- 任何真机/CI 输入到达时，对应外部依赖项插队到当前大项之后。
